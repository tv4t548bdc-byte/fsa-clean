# FSA Clean - Site institucional

Site estático (HTML, CSS e JS puros). Sem build.

## Publicar na Vercel via GitHub
1. Crie um repositório no GitHub e envie o conteúdo desta pasta.
2. Em vercel.com/new, importe o repositório.
3. Framework Preset: Other. Deixe Build Command e Output Directory em branco. Clique em Deploy.
